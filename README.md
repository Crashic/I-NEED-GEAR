# I NEED GEAR

Приложение Windows и аддон WoW для обмена снаряжением через Supabase.
Программа и аддон обновляются через публичные GitHub Releases.

## Установка для друзей

1. Откройте [последний релиз](https://github.com/Crashic/I-NEED-GEAR/releases/latest).
2. Скачайте `INEEDGEAR.exe` в отдельную доступную для записи папку, например «Документы\I NEED GEAR».
3. Запустите программу, откройте «Настройки» и выберите папки `Interface\AddOns`
   и `WTF\Account\<АККАУНТ>\SavedVariables` вашего клиента.
4. Нажмите «Установить аддон». В игре окно открывается командой `/ing`.
5. Для обмена сохраните снаряжение в аддоне, полностью закройте игру и нажмите
   «Синхронизировать снаряжение» в программе.

При запуске программа проверяет новые версии. Также доступна кнопка
«Проверить обновление». Перед установкой обновления закройте WoW.
Настройки хранятся в `%LOCALAPPDATA%\INEEDGEAR\settings.json`.
Существующие настройки из папки программы переносятся при первом запуске.
Обновление сохраняет предыдущий `.exe` с суффиксом `.previous` и аддон
в папке `INEEDGEAR.previous`; при ошибке замены выполняется восстановление.
Это восстановление при ошибке установки, а не проверка работоспособности новой версии в игре.

## Публикация разработчиком

Сборка выполняется на Windows-сервере GitHub Actions, локальный Python не требуется.

1. Измените исходники в репозитории и сохраните изменения в основной ветке.
   Кнопка публикации собирает именно исходники GitHub, а не локальные несохранённые файлы.
2. Откройте вкладку **Actions → Сборка и публикация → Run workflow**.
3. Укажите новую версию, например `1.0.1`. Она должна быть выше последнего релиза.
4. Дождитесь успешного завершения. GitHub соберёт обычную и dev-версии,
   проверит запуск, упакует аддон и опубликует релиз.
   Незавершённые загрузки останутся черновиком.

Альтернатива: скачайте `INEEDGEAR-DEV.exe` из релиза и нажмите
«Опубликовать обновление». Она запускает тот же процесс GitHub Actions.
Кнопка подтверждает отправку запроса, окончательный результат смотрите во вкладке Actions.
Первую сборку запускают через сайт GitHub.

Для кнопки публикации нужен fine-grained token, ограниченный этим репозиторием,
с правом **Actions: Read and write**. Сохраните его только в пользовательской
переменной Windows `INEEDGEAR_GITHUB_TOKEN`.
После изменения переменной перезапустите программу; dev-версия также умеет
читать актуальное значение из пользовательских переменных Windows.
**Contents: Read and write** и **Workflows: Read and write** нужны при первоначальной
загрузке или изменении исходников и workflow через API, а не друзьям.

Токен не хранится в исходниках и не входит ни в один `.exe`.
Сама сборка использует краткоживущий `GITHUB_TOKEN`, выдаваемый GitHub Actions.
Пользовательская сборка исключает модуль публикации. Dev-сборка тоже публична,
но без локального токена публиковать ничего не может.
Обновления dev-версии сохраняют dev-режим.
С версии 1.0.1 проверка версии скачивает публичный `manifest.json` через
`releases/latest/download`, без обращения к REST API GitHub и его анонимному лимиту.
После проверки версии загрузки привязываются к конкретному релизу.

## Разработка

Требуется Python 3.12. Зависимости: `python -m pip install -r requirements.txt`.
Запуск: `python main.py`; версия разработчика: `python main_dev.py`.
Проверки: `python -m unittest discover -s tests -v`.
Аддон находится в `addon/INEEDGEAR`; интерфейс клиента в `.toc` сохранён
из исходного проекта (`16001`), совместимость нужно проверить в вашем WoW Forever.
Раздел «Инсты» пока является заглушкой исходного аддона.

Supabase используется только для данных персонажей. Публичный ключ `anon`
не заменяет RLS: политики таблицы `characters` проверяются в панели Supabase.
Проект не меняет схему базы и её политики. Синхронизация требует существующей таблицы
с полями `player_key` (уникальный ключ), `equipped`, `wishlist`, `last_update`.

Манифест релиза содержит размеры и SHA-256 файлов. Это проверка целостности,
не отдельная цифровая подпись. Запросы обновлений выполняются анонимно по HTTPS.
При ограничении запросов GitHub повторите проверку позднее.
Google Drive и зависимость `gdown` больше не используются.
